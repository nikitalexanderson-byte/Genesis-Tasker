# GENESIS Android packages

Published Android packages are distributed from [genesiscalendar.com](https://genesiscalendar.com/). Binary releases and signing keys are kept outside this source repository. Use the website's current download metadata to identify the available package.

The web/API deployment preserves existing Android downloads and does not build or publish an Android release. A separately authorized Android update must preserve the package identifier and release certificate, increase versionCode, and retain installed user data. See [deployment](../docs/DEPLOYMENT.md) and [testing](../docs/TESTING.md) for the current workflow and verification limits.
