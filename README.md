# Genesis Tasker

Genesis Tasker — календарь, планировщик личных и совместных дел, трекер привычек и пространство для дневника и наблюдений. Проект помогает организовать повседневную работу, долгосрочные проекты и личные практики. Григорианские даты, сакральный годовой круг и лунные циклы используются вместе с обычными задачами и напоминаниями.

В репозитории находятся исходники веб-приложения, PWA, PHP API и нативного Android-клиента. Действующий сайт — [genesiscalendar.com](https://genesiscalendar.com). Публикация исходников здесь не обновляет сайт или установленное приложение.

## Возможности

- Календарь месяца и года, фактический сегодняшний день, три календарные системы, часовые пояса, повторения и напоминания.
- Личные задачи, проекты и подпроекты, категории, теги, поиск и сортировка; отдельное подключение Google Calendar и Google Tasks после Google-входа.
- Привычки, измерения, таймеры, история исправлений, отчёты, прогресс и награды; сон, настроение и другие трекеры.
- Совместные пространства, роли, задачи, доски, Гант, обсуждения, уведомления, автоматизации и личные сообщения.
- Майндмепы, дневник, сохранённые советы, дневник сновидений; Стойхейон, Аврора и связанные авторские разделы.
- Physis: тренировки, питание, личные измерения, добавки и лекарства с ограничением доступа серверной политикой.
- Личный импорт/экспорт, зашифрованные контейнеры и очереди поддерживаемых офлайн-операций.
- 14 языков, светлая и тёмная схемы; компьютер, мобильный браузер, установка PWA и отдельный Android-клиент.

Подробности и тарифные ограничения: [обзор проекта](docs/PROJECT_OVERVIEW.md). Наличие исходников модуля не означает, что он включён для каждого пользователя.

## Стек и структура

Веб: React 19, TypeScript 5.9, Vite 8, vinext и CSS. Основной вариант для PHP-хостинга собирается отдельной конфигурацией Vite. PHP API использует SQLite, Sodium и сессии. Android использует Kotlin, Jetpack Compose, Room и WorkManager. Вспомогательная сборка vinext/Cloudflare сохранена для локальной разработки и серверного рендеринга; основное приложение обслуживает PHP API.

```text
app/                  интерфейс, календарная и предметная логика, переводы
app/physis/           здоровье, тренировки, питание и уход
app/aurora/           модели, каталоги и интерфейс Авроры
web/                  вход статической web-сборки
server/public/        публичная часть HTTP API
server/src/           права, синхронизация, сервисы и хранилище
server/migrations/    последовательные SQLite-миграции
server/resources/     серверные политики, тарифы и справочники
android/              нативный клиент и его тесты
public/               изображения, шрифты, PWA и публичные ресурсы
assets/               исходные графические ресурсы
tests/                проверки логики, совместимости и рендеринга
scripts/qa/           изолированные API- и браузерные проверки
scripts/performance/  воспроизводимые синтетические измерения
docs/                 архитектура, настройка, методика и результаты
```

## Окружение и установка

Проверяемое окружение: Node.js **24.19.0**, pnpm **11.19.0**, PHP **8.4** с `pdo_sqlite`, `sqlite3`, `sodium`, `mbstring`, `openssl`, `curl`, `fileinfo`. В package.json сохранён минимальный Node.js 22.13; результаты текущей проверки относятся к 24.19.0. Для Android нужны JDK **25**, Android SDK **37.2**, Build Tools **37.0.0**; Gradle Wrapper включён в исходники.

```sh
git clone https://github.com/nikitalexanderson-byte/Genesis-Tasker.git
cd Genesis-Tasker
npx --yes pnpm@11.19.0 install --frozen-lockfile
```

Если pnpm нужной версии установлен, далее используйте `pnpm`. `pnpm-lock.yaml` — единственный актуальный lock-файл JavaScript-зависимостей. Пакет остаётся `private`, автоматическая публикация npm отключена.

## Локальный запуск без внешних аккаунтов

```sh
pnpm build:web
pnpm qa:serve
```

Сервер печатает адрес приложения и ссылки входа в синтетические аккаунты пяти тарифов. Откройте ссылку входа, затем приложение. По умолчанию используются только `127.0.0.1:4380` и `127.0.0.1:4381`. SQLite, сессии и случайные ключи создаются в новом каталоге `output/qa/`; внешняя почта и `curl_exec` отключены. При штатном завершении тестовый runtime удаляется. Для остановки нажмите Ctrl+C.

На Windows PHP для QA при необходимости загружается с официального сайта: версия и SHA-256 закреплены в `scripts/qa/backend-php.mjs`. На других системах используется совместимый `php` из PATH. Свой runtime задаётся через `GENESIS_QA_PHP`.

Для интерфейса с HMR доступна команда `pnpm dev`. Она сама по себе не запускает PHP API и не настраивает Google-вход. Переменные и тестовые интеграции описаны в [LOCAL_DEVELOPMENT.md](docs/LOCAL_DEVELOPMENT.md).

## Проверки и сборка

```sh
pnpm lint
pnpm typecheck
pnpm test                 # аудит переводов, vinext build, tests/*.test.mjs
pnpm build:web            # локальная статическая сборка и её проверки
pnpm exec playwright install chromium
node scripts/qa/backend-run.mjs --run-id=local-backend
node scripts/qa/backend-api.mjs --run-id=local-api
node scripts/qa/web-run.mjs --run-id=local-web
pnpm benchmark --output=output/performance.json
```

Для повторного QA выбирайте новый `run-id`: прошлые результаты сохраняются. `pnpm qa:full` выполняет автоматические проверки web/API и Android и сохраняет общий отчёт. `pnpm qa:full --scope=web` явно ограничивает проход web/API; он не подтверждает Android. Подробности: [TESTING.md](docs/TESTING.md), [PERFORMANCE.md](docs/PERFORMANCE.md), [VERIFICATION.md](docs/VERIFICATION.md).

Android без release-ключей:

```sh
cd android
./gradlew :app:testDebugUnitTest :app:assembleDebug \
  -PgenesisUrl=https://localhost.invalid/ \
  -Pkotlin.compiler.execution.strategy=in-process --max-workers=2 --no-daemon
```

На Windows используйте `gradlew.bat` и заключайте аргументы `'-PgenesisUrl=…'`, `'-Pkotlin.compiler.execution.strategy=in-process'` в кавычки. Укажите `JAVA_HOME` и `ANDROID_HOME`. Debug package имеет суффикс `.debug` и не заменяет основное приложение. Подписанные APK/AAB и ключи в репозиторий не включены.

## Данные и безопасность

Личная рабочая копия и очередь изменений хранятся на доверенном устройстве. Личный workspace передаётся в AES-GCM-контейнере; ключ доступен серверу в отдельно зашифрованном виде для входа с нового устройства. Это **не zero-knowledge E2EE**. Google OAuth-токены остаются на сервере и шифруются Sodium. У сообщений и отдельных контейнеров есть собственные модели ключей.

Сервер проверяет сессию, CSRF, роли и тарифы. Workspace и совместные сущности используют версии и повторяемые операции, чтобы потерянное подтверждение не становилось повторной записью. История привычек сохраняет ранее заработанные начисления. Схемы и writer-протоколы старых клиентов сохранены.

Резервирование должно включать согласованную SQLite-копию и необходимые закрытые ключи/конфигурацию вне web-root. Исходники не заменяют резервную копию данных. Миграции применяются приложением при обращении к БД; запуск против production не является частью локальных проверок. Границы доверия: [PRIVACY-ARCHITECTURE.md](docs/PRIVACY-ARCHITECTURE.md).

`server/config.php`, `server/var/`, настоящие `.env`, токены, SQLite-базы и signing keys не должны попадать в Git. Для настройки есть безопасные примеры. Уязвимости без секретов и персональных данных сообщайте через [контакт безопасности](https://genesiscalendar.com/.well-known/security.txt).

## Ограничения и участие

Реальные Google OAuth/Calendar/Tasks, платежи, push/email, магазин и физические устройства требуют отдельных тестовых аккаунтов и окружений. Локальные заглушки не подтверждают эти сервисы. Проверенные и непроверенные состояния перечислены в отчёте. Production-данные не используются для экспериментов.

Порядок изменений — в [CONTRIBUTING.md](CONTRIBUTING.md). Автоматический `Source checks` проверяет исходники и собирает debug-клиент. Отдельный `Deploy` запускается только вручную для проверенного текущего SHA ветки `main` и публикует сайт/API на Hostinger с резервированием runtime. Он сохраняет Android-загрузки и не выпускает APK/AAB. Порядок выпуска и отката — в [DEPLOYMENT.md](docs/DEPLOYMENT.md).

Лицензия на проект пока **не выбрана**. Публичная доступность исходников сама по себе не предоставляет открытую лицензию. Уведомления и лицензии сторонних ресурсов сохранены в соответствующих каталогах.
