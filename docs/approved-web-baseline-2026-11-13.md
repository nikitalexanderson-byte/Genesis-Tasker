# Утверждённая базовая версия сайта

13 ноября 2026 владелец подтвердил текущую работающую версию сайта и поручил:
«назад не откатывай больше без моих указаний. только вперед можно изменения
на сайте добавлять». Это правило действует для всех дальнейших задач.

- Сайт: https://genesiscalendar.com.
- Репозиторий: nikitalexanderson-byte/Genesis-Tasker, main.
- Утверждённый production commit: 59b05b165875f87848888d70aabca52b6837d876.
- Успешный Deploy: 43447998003, 13 ноября 2026.
- Метка базы: web-approved-2026-11-13.
- Веб-интерфейс совпадает с принятой публикацией 94ab5d3 от 11 ноября;
  большие зелёные шапки из старого calendar-genesis устранены.

Следующие изменения делаются от актуального main с сохранением принятого
оформления, функций, ассетов, переводов и пользовательских данных.
Нельзя автоматически возвращать эту или любую другую старую версию:
базовая метка служит точкой сравнения. Для отката, в том числе через
restore_web_only, нужно новое прямое указание владельца на конкретный откат.

Android продолжает обновляться независимо. Текущая установленная и
опубликованная версия — 3.3.0/142. Выпуск приложения не разрешает выкладку
сайта/API и не должен менять утверждённый веб-интерфейс. Разделение
репозиториев не выполнялось: владелец задал вопрос о целесообразности,
а не поручил создать новые репозитории.
