# Membership owner exchange, 22 November (candidate code)

Both clients now have matching full-plan review requests and owner-approval
contracts. The request fingerprint binds actor/intent, the exact projected ACL
changes, the complete expected scope list and every preview coordinate/role/
manifest. A scope owner's separate protected review records the compared full
fingerprint and explicit complete device roles before opening any scope or
preparing keys. Only an independently pinned, enrolled owner device can create
that scope's fresh rotation; its signed packet is saved before export. It cannot
apply ACL changes or rotate a scope alone outside the existing atomic batch.

The initiating journal saves an incoming typed approval as unverified input
before directory IO. Verification requires the independently accepted authority,
the exact historical checkpoint/epochs/resource, a non-revoked owner signer,
signature, the full live roster, capsules and sealed object manifest. Only a
verified import can enter preparation. Missing owners stop preparation explicitly;
the client does not manufacture another owner's signature. Existing own-scope
rotations remain immutable at their established changeHash key.

Observed signed directory history is retained as a checkpoint; a hypothetical
appended approval is never saved as accepted history. All rotations and the
personal authorization are assembled into one immutable batch. Unknown POST
outcomes retry that batch, without refresh/re-sign/rekey. The complete receipt
is compared to every exact command's chained checkpoint/epochs/revocations and
then to actual signed directory history. Where this device is a surviving
recipient, the normal scope port also opens its current/history capsules.

Real web/native account/session/workspace/lifecycle-bound ports and bridges now
compose the initiator product and owner review journals. Retained custody has a
separate verifier for imported owner evidence: verified entries prove their
scope-owner signature and complete signed roster; unverified pasted packets are
only typed inert personal input. No outsider signer becomes this device's signer
or an executable generic control packet. Old journals/packets remain intact.

This is uncompiled/untested candidate code. No tests/typecheck/lint/build/CI,
push/publication, devices or Play changes ran. Coverage remains9/20.

Still required in the code phase: normal role/remove/project-grant input adapters
with complete durable pre-network input; independently computed affected-scope
closure (including inherited topology); normal initiator/owner review UI with
verified user/device attribution and14-language text; invitation request/
consumption; semantic resolution/cancellation for stale or partially prepared
plans. These bridges alone do not complete normal membership or activation.
