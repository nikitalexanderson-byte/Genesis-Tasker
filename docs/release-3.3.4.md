## Исправления

- **Второй шаг моделирования.** На оптимизированном QA APK Samsung
  воспроизведены пустое окно и отказ «Назад» после «Дальше» с темой «Дом».
  Формула `Ζεὺς Ἑρκεῖος` передавала пробел в калькулятор одного слова,
  вызывала `RangeError` и размонтировала React root. Расчёт исключает только
  пробельные разделители, сохраняя проверку букв; проверены все 81 сочетание
  исходного и внешнего секторов. Нативные закрытие и «Назад» работают при
  отсутствии DOM, ошибке bootstrap и неотвечающем renderer. Старт ограничен
  15 секундами; шифрование и сохранённые работы сохраняются.
- **Выход при смене темы на Samsung.** Журнал подтвердил закрытие системой
  задачи, корнем которой был отключаемый launcher alias. Значки теперь
  открывают короткоживущую `LauncherActivity` с отдельной taskAffinity,
  которая передаёт управление постоянной `MainActivity`. Старые задачи
  с корнем alias завершаются при обновлении без изменения хранилищ.
  Проверки подтверждают постоянный baseIntent и сохранение task ID при
  всех восьми вариантах значка. Android 13+ переключает alias атомарно;
  предыдущие Android сначала включают нужный значок.
- **Суббота.** В светлых палитрах выбранная суббота имеет чёрную рамку 3dp.
  В тёмных палитрах — более тёмную графитовую кромку, мягкий блик и менее
  яркое свечение. Остальные дни и принятые палитры сохраняются.
- **Начало года в марте.** Предложение расположено сразу под годовой
  навигацией; фон, текст, действие и закрытие используют общие компоненты.
  Пояснение читается в светлых палитрах. Сохранены все 14 переводов,
  закрытие предложения и настройка начала года.
- **Дневник.** Расширенная приёмка выявила пропадавшую кнопку возврата из
  избранного и архива. Навигационный слот общей шапки теперь читает
  исходное состояние вкладки внутри своего Compose scope.
- В миниатюрах второго шага убраны только перекрывавшие иллюстрации
  декоративные надписи лицевой стороны. Иллюстрации, буквы, отдельные
  названия, доступные описания и полные тексты карт сохранены.
- Один вычитанный файл `releases/android-3.3.4-notes.json` используется
  приложением и Google Play. Все 14 примечаний короче 500 символов.

- **Экран входа.** В подписанном кандидате 146 выявлено перекрашивание
  текста и карточек светлой палитрой поверх постоянно тёмного artwork.
  Локальный CompositionLocalProvider сохраняет авторские цвета только
  экрана входа. Пиксельная проверка воспроизвела дефект до исправления.
  Для обновления уже установленного кандидата 146 принят versionCode 147.

## Достоверность и ограничения

- Исходный полный прогон сохранён с ошибками. Старые ожидания тестов
  обновлены под принятый интерфейс: свёрнутые настройки, отдельные

- Исправления QA для 146 не меняли рабочие APK. Debug APK кандидата 146:
  `153a5016354b253e954e2b8f0ce2e1347267fea1e63e846e0696b4028b2d1565`;
  оптимизированный QA APK:
  `b6cd51500ef7c8bcb0cebb29a3d92c09ba27d00cfe91e3a56d929509c25f9413`.
  Native source hash включает сами тесты, поэтому меняется при их доработке;
  артефакты и исходники runtime проверяются отдельно.
- Stock Chrome/WebView **69.0.3497.100** в образе Android 8 не запускает
  современный модуль моделирования. Проверены локализованная ошибка,
  нативное закрытие и «Назад», без зависания приложения. Для полного
  моделирования на таком устройстве нужен обновлённый WebView.
- Сверка ключей не считается ручной вычиткой всех исторических строк.
  Живой вход Google, реальные покупки/возвраты и отправка сообщений
  другим людям не входят в эти изолированные прогоны. Платные операции
  и пользовательские записи не использовались как тестовые данные.
- Первый локальный web-прогон имел таймаут и зависимый сбой; полный
  затронутый premium4life/trial/header набор повторён: 105/105.
