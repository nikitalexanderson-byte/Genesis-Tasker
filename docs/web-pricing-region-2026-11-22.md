# Срочное исправление валюты сайта,22 ноября2026

Сравнение тарифов внутри авторизованного приложения брало валюту единственного
подключённого провайдера ЮKassa. Поэтому английский интерфейс в США показывал
RUB333/555/777, хотя международная публичная витрина уже была в USD.

По прямому поручению владельца отображение отделено от выбора checkout:

- Английский и остальные нерусские интерфейсы показывают фиксированные USD.
- Другая/неизвестная страна показывает USD также на русском. Только русский
  интерфейс с положительной Россией показывает RUB.
- ЮKassa скрыта до положительного текущего определения России. Иностранный
  IP/разрешённая позиция имеют приоритет при противоречии сигналов. Нет запроса
  нового разрешения геолокации. Язык/часовой пояс/старый выбор валюты не являются
  доказательством нахождения в России. IP читается свежим anonymous/no-store
  запросом; отсутствие результата не включает российский checkout.
- За пределами разрешённого региона quote ЮKassa не запрашивается; старая quote
  не отображается и кнопка не создаёт новый заказ. Цены USD не включают Paddle.
- Те же правила применены к оплате Авроры/моделирования. Ранее созданные заказы,
  суммы/валюты возвратов и проверка старого платежа остаются достоверными.

Цены каталога сохранены: USD4/7/10 за месяц,40/70/100 за год,Elite160.
RUB333/555/777,3330/5550/7770 иElite12900 сохранены для соответствующего региона.
Новые тексты/локализации не добавлялись, прежние14 языков и оформление сохранены.
