# Android 3.3.3 / 145 — подготовка

Рабочая ветка `codex/android-3-3-3`, база `Genesis-Tasker/main`:
`86a71dd7`. Поручения владельца от 15 ноября 2026 относятся к Android.
После просмотра снимков 16 ноября владелец разрешил выпуск 3.3.3 в
Google Play Open testing, обновление подключённого realme и размещение APK
на сайте. Веб/API не публикуются; Production и страны не меняются.

   затем устранить дефект. Уточнение владельца: ошибка сразу при открытии карты.

4. Обновить мобильный метод моделирования будущего до текущего сценария сайта.

   недели — золотая, серебряная, красная, зелёная, синяя, фиолетовая,

7. Убрать дополнительную подложку даты/погоды на «Сегодня» вечером и ночью.

10. 16 ноября владелец принял оформление календаря. Эксперимент следующего

## Подтверждённые причины и исправления

- В майндмепах строка `Authentication request failed` принадлежит общему
  транспортному исключению, которое также представляет сетевые, HTTP,
  серверные и протокольные сбои. При открытии выполнялся refresh, а UI
  показывал действия сохранения даже для ошибки чтения уже синхронизированной
  карты. Теперь чтение и запись имеют разные действия восстановления,
  причины отображаются локализованно, отмена корутины не превращается в ошибку.
  Неавторизованное чтение может однократно перепроверить сессию; успешная
  перепроверка обновляет также live receipt прав доступа. Неопределённая запись
  повторяется только через прежний сохранённый operationId репозитория.
  Отдельный тест доказал сохранение кешированной карты и отсутствие лишних PUT
  при повторной загрузке после сетевого сбоя.
- Причина отказа конкретного запроса на устройстве владельца пока не
  подтверждена: снимок не содержит HTTP-статуса. Добавлена запись только
  категории и HTTP-статуса, без cookie, ключей и содержимого карты.
- Для олимпийцев перенесены текущие общие компоненты сайта с локальными
  каталогами, поиском, вариантами расчёта, корнями, словами, источниками,
  сравнениями и переходами к буквам/секторам. Детальная карточка проверена
  в 14 языках. При визуальном контроле выявлен реальный `100dvh = 0px`
  внутри WebView: DOM существовал, но высота карточки равнялась 24px.
  Нативная точка входа теперь измеряет реальную высоту viewport в пикселях;
  проверка требует видимую высоту карточки во всех 14 языках.
- Для метода используется текущий `GnoWizard` сайта вместо старой стартовой
  точки Aurora. Прежние работы Aurora остаются доступны через общий мастер,
  шифрование и нативный мост сохраняются. Полностью открытые три карты
  передаются как дополнительный временной расклад, новые карты не бросаются.
- Ночное затемнение за датой/погодой убрано в общем reading-area модификаторе.
  Дневной текст в тёмных палитрах теперь белый с мягкой тенью; светлая подложка
  для прежнего тёмного текста больше не применяется.
- Общая проверка контраста выбранной ячейки заменяла тематическую рамку чёрной.
  Тёмный календарь теперь использует отдельную обводку по дню недели;
  все дни имеют одинаковую тёмную заливку своей схемы без изменения
  при выборе, цифры и подписи белые. Движущийся градиент и шесть тонких
  внешних штрихов дают блик/свечение без размытия всего календаря.
  Состояние анимации читается при рисовании, без повторного измерения сетки.
  Предыдущие снимки сохранены в `output/qa/android333-before-cell-revision/`.

## Ограничения перед выпуском

Не выполнены: подтверждение исходного сетевого сбоя и восстановления входа
на живом аккаунте, фактическая серверная погода, физический планшет, полный
проход всех шагов/платежей/создания задач нового метода на устройстве и
смысловая вычитка каждого текста всех 14 языков непосредственно в приложении.
Автоматический i18n-аудит и проверка открытия чтения не заменяют такую вычитку.
Тексты чтений и алгоритмы повторно использованы из принятого сайта.
Старые исторические UI-прогоны 3.1.x целиком не перезапускались; их вызовы
олимпийцев приведены к новой сигнатуре для успешной компиляции.
Release notes 3.3.3 и окончательная приёмка выпуска ещё не финализированы.
Подписанный выпуск, сайт, Play и основное приложение не публиковались/не обновлялись.
